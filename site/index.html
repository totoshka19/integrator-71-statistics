    Как читать эти числа

    MR — принятый результат

    Дата — день слияния в московском времени. Каждый MR считается один раз в общем итоге. Совместный MR виден у каждого участника, поэтому сумму их MR нельзя использовать как итог команды.

    SP — оценка работы

    Шкала 1, 2, 3, 5, 8, 13 описывает сложность выполненной работы. Связанные MR могут быть одной единицей; SP делятся по долям. Переключатель показывает исходную оценку или её версию с ручными поправками.

    Строки — объём изменений

    Код: добавленные + удалённые непустые строки без комментариев. Тесты, документация и конфигурация учитываются отдельно. Генерируемые файлы, зависимости, графика и бинарные файлы исключены. При доказанном восстановлении прежнего результата учитывается только добавочная работа.

    Неизвестное остаётся неизвестным

    «—» означает неполный итог; рядом указана известная часть. Ноль появляется только при подтверждённых данных. Повторный перенос результата не добавляет SP и строки. Числа не являются рейтингом людей или оценкой производительности.
