# Статистика команды Интегратор 7/1

**Версия:** 0.5.1

**Дата:** 17.10.2026

Статическая страница: https://totoshka19.github.io/integrator-71-statistics/

Пакет содержит только публичные показатели и ресурсы сайта. Источники GitLab, приватные описания, настройки сбора и инструменты анализа хранятся отдельно. Сайт не требует API, CDN или внешних шрифтов.

Для GitHub Pages используется GitHub Actions и ветка `pages`. В настройках репозитория выбрать **Pages → Source → GitHub Actions**, а для environment `github-pages` разрешить ветку `pages`. Workflow выгружает только `site/`. После первого размещения проверить актуальный запуск Actions и открытие сайта с префиксом репозитория.

Изменения сайта публикуются после проверки и коммита нового публичного пакета. Здесь нет сборщика GitLab или автоматического анализа SP. `publication-manifest.json` содержит контрольные суммы всех файлов пакета, `site/manifest.json` — ресурсов сайта.

MR считаются уникально, SP и строки распределяются по долям. Прочерк означает неизвестный полный итог; известная часть указывается отдельно. Изменения кода — добавленные + удалённые непустые строки без комментариев. Методика и ограничения доступны на странице.

Страница содержит выбор группы и исполнителя, общий график трёх метрик и таблицу принятых MR. Карточка работы показывает публичное описание результата, SP, строки и разрешённые метаданные MR. При включённом экспорте метаданных доступны номер, модуль, заголовок, число файлов и ссылка GitLab; доступ к самому проекту определяется его настройками. Список файлов, diff и внутренние описания в пакет не входят. Периоды отсчитываются от последнего сохранённого дня. Дополнительные фильтры и методика находятся в раскрываемом блоке; CSV сохраняет дневные итоги и строки участников.

Набор за 01.09–16.10.2026 содержит 218 MR: 210 новых результатов и 8 повторных переносов. Подготовлены оценки всех новых результатов — 791 SP; строки полностью посчитаны по loc-v1.1 — 65 461 строка исходного кода. За 10–16.10: 30 MR / 122 SP / 11 586 строк кода. Период завершён и сверён 17.10.2026. Новая часть MR !99 отделена от повторного переноса Sentry: учтены только подключение готовых проверок к CI, 1 SP и две строки конфигурации. Неизвестных итогов SP и строк нет. У четырёх старых MR недоступна часть сведений связанных задач; измерения и оценки по сохранённым изменениям подтверждены с этим ограничением. Повторные переносы и ранее принятая функциональность при восстановлении после отката не начисляются заново. Тесты, документация/данные и конфигурация имеют отдельные категории. Это относительные оценки объёма и сложности изменений, а не подтверждение прохождения тестов или работы production.

Workflow основан на [официальной документации GitHub Pages](https://docs.github.com/en/pages/getting-started-with-github-pages/using-custom-workflows-with-github-pages).
