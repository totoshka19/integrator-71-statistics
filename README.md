# Статистика команды Интегратор 7/1

**Версия:** 0.4.0

**Дата:** 07.10.2026

Статическая страница: https://totoshka19.github.io/integrator-71-statistics/

Пакет содержит только публичные показатели и ресурсы сайта. Источники GitLab, приватные описания, настройки сбора и инструменты анализа хранятся отдельно. Сайт не требует API, CDN или внешних шрифтов.

Для GitHub Pages используется GitHub Actions и ветка `pages`. В настройках репозитория выбрать **Pages → Source → GitHub Actions**, а для environment `github-pages` разрешить ветку `pages`. Workflow выгружает только `site/`. После первого размещения проверить актуальный запуск Actions и открытие сайта с префиксом репозитория.

Изменения сайта публикуются после проверки и коммита нового публичного пакета. Здесь нет сборщика GitLab или автоматического анализа SP. `publication-manifest.json` содержит контрольные суммы всех файлов пакета, `site/manifest.json` — ресурсов сайта.

MR считаются уникально, SP и строки распределяются по долям. Прочерк означает неизвестный полный итог; известная часть указывается отдельно. Изменения кода — добавленные + удалённые непустые строки без комментариев. Методика и ограничения доступны на странице.

Исторический набор за 01.09–05.10.2026 содержит 165 MR: 158 новых результатов и 7 повторных переносов. Подготовлены оценки всех новых результатов — 561 SP; строки полностью посчитаны по loc-v1.1 — 43 955 строк исходного кода. Повторные переносы и ранее принятая функциональность при восстановлении после отката не начисляются заново. Тесты, документация/данные и конфигурация имеют отдельные категории. Это относительные оценки объёма и сложности изменений, а не подтверждение прохождения тестов или работы production.

Workflow основан на [официальной документации GitHub Pages](https://docs.github.com/en/pages/getting-started-with-github-pages/using-custom-workflows-with-github-pages).
